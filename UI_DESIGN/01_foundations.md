# WealthTracker UI Design — Foundations

## Visual Identity

**Style:** Clean, professional, finance-first. Inspired by modern banking apps (Revolut, Robinhood).
Calm deep blue as primary brand colour with vivid category accents for quick visual scanning.
Heavy use of Cards and subtle gradients on hero surfaces. Light/Dark mode supported throughout.

## Spacing Scale

`4 · 8 · 12 · 16 · 20 · 24` dp — always multiples of 4.

| Context                        | Value |
|-------------------------------|-------|
| Default screen padding (all)   | 16 dp |
| List item padding (all)        | 12 dp |
| Card internal padding          | 14–16 dp |
| Between form fields            | 12 dp |
| Between list items (separator) | 8 dp  |
| Between icon and label         | 8 dp  |
| Between section headers        | 24 dp |

---

## Elevation & Surfaces

- **Cards:** `Card` with default M3 elevation (tonal fill, no hard shadow in light mode; slightly elevated in dark).
- **AppBar:** `AppBar` flat, no elevation, uses `colorScheme.surface` background.
- **BottomNavigationBar:** `NavigationBar` with `surfaceVariant` background, indicator pill on selected item.
- **Dialogs:** `AlertDialog` with rounded corners (`borderRadius: 28`), surface colour background.
- **Hero header (Dashboard):** `LinearGradient` from `primaryContainer` → `secondaryContainer`, full-width, 24 dp vertical padding.

## Motion & Animation

- **Page transitions:** Default `MaterialPageRoute` slide (no custom transitions needed).
- **Pie chart tap:** Section expands radius 55 → 65 dp with tooltip badge appearance.
- **Loading states:** `CircularProgressIndicator` centered, `strokeWidth: 2` inside AppBar actions.
- **Refresh indicator:** `RefreshIndicator` on Dashboard scroll.
- **Dialog open/close:** Default M3 scale+fade.
- **Snackbars:** Bottom-anchored, 2-second auto-dismiss for save confirmations.

## Responsive Breakpoints

| Width         | Layout                                               |
|---------------|------------------------------------------------------|
| < 600 dp      | Single column. Stack everything vertically.          |
| 600–800 dp    | Single column with wider margins.                    |
| > 800 dp      | Dashboard category cards switch to 2-column grid (`crossAxisCount: 2`, `childAspectRatio: 2.2`). All other screens remain single-column. |

The breakpoint check in code: `MediaQuery.of(context).size.width > 800`.
